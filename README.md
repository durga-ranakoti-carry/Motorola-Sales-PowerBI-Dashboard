# 📊 Motorola Sales & Business Intelligence Dashboard

An interactive, end-to-end Power BI dashboard designed to analyze retail sales performance, customer ratings, and transaction behavior for Motorola. This project transforms raw transactional data into clean, decision-ready visual insights.



## 🚀 Dashboard Preview
*(Aap yahan apne Power BI dashboard ka screenshot upload karke add kar sakti hain)*



## 📈 Key Performance Indicators (KPIs)
* **Total Sales:** 308M
* **Total Quantity Sold:** 8K
* **Total Transactions:** 2K
* **Customer Feedback & Ratings:** Multi-tier user satisfaction metrics



## 🧩 Key Visuals & Features
1. **Geographical Sales Map:** Visualizes regional sales distribution across key territories.
2. **Monthly & Daily Trends:** Line and area charts showing sales fluctuations over time.
3. **Payment Method Distribution:** Donut chart breaking down customer preferences for payment channels (UPI, Credit/Debit cards).
4. **Customer Ratings Breakdown:** Bar charts evaluating user satisfaction tiers.
5. **Interactive Filtering:** Sidebar month navigation and global slicers for dynamic data exploration.



## 🛠️ Tools & Skills Demonstrated
* **Microsoft Power BI:** Dashboard design, layout formatting, and theme styling.
* **Data Modeling:** Connecting multiple tables for seamless reporting.
* **Power Query:** Data transformation, cleaning, and preprocessing.
